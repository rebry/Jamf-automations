# Jamf Automations

Small scripts, configuration profiles and Extension Attributes I use to make day-to-day work with
Jamf Pro easier. Each folder has its own README with what it does and how to set it up in Jamf Pro.

| Folder | What it does |
|---|---|
| [eMudhra Remediation](eMudhra%20Remediation) | Removes the leaked eMudhra roots from `/etc/ssl/cert.pem` and conda's CA bundles, with matching Extension Attributes |

Everything here is shared as it is, so I would recommend testing in a pilot group before you scope
anything to production.
